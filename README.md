# J-MO'S Fordsburg Demo Website

A premium-style demo landing page for J-MO'S Fordsburg, built as a lightweight static site for client presentation.

## Preview locally

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` – page structure
- `styles.css` – visual design and responsive layout
- `script.js` – lightweight footer enhancement

## Notes

This is a polished demo designed for presentation and can be refined with exact branding, pricing, full menu sections, and business photos if needed.
